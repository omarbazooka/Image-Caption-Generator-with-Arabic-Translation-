Project pipeline

Two AI stages, one simple flow

The original project pipeline remains BLIP captioning followed by MarianMT Arabic translation.

01
IMG

Image input

The uploaded image is validated and prepared for inference.

02
BLIP

Caption generation

The core backend uses Salesforce BLIP to generate an English caption.

03
AR

Arabic translation

MarianMT translates the generated English sentence into Arabic.

04
UI

Bilingual result

The frontend displays both captions in a presentation-friendly layout.
